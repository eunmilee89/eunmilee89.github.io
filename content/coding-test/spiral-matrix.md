## 문제

양의 정수 `n`이 주어질 때, `n × n` 배열에 1부터 `n²`까지의 정수를 `[0][0]`부터 시계방향 나선형으로 배치한 이차원 배열을 반환한다.

- `1 ≤ n ≤ 30`

| n   | result                                                                                                  |
| --- | ------------------------------------------------------------------------------------------------------- |
| `4` | `[[1, 2, 3, 4], [12, 13, 14, 5], [11, 16, 15, 6], [10, 9, 8, 7]]`                                       |
| `5` | `[[1, 2, 3, 4, 5], [16, 17, 18, 19, 6], [15, 24, 25, 20, 7], [14, 23, 22, 21, 8], [13, 12, 11, 10, 9]]` |

![계곡에서 물아일체로 흐르는 성동일](https://img.sbs.co.kr/sbscnbc/upload/2013/06/30/10000367236.jpg)

## 접근

나선은 "오른쪽 → 아래 → 왼쪽 → 위" 순서를 반복하며, 벽이나 이미 채운 칸을 만날 때마다 다음 방향으로 꺾는다. 방향별 이동량을 배열로 두면 방향 전환을 인덱스 증가 하나로 처리할 수 있다.

1. `n × n` 배열을 0으로 채워 만든다. 0은 "아직 비어 있음"을 뜻한다.
2. 행 이동량 `deltaX = [0, 1, 0, -1]`, 열 이동량 `deltaY = [1, 0, -1, 0]`으로 네 방향을 정의한다.
3. 현재 칸에 숫자를 넣고, 현재 방향으로 한 칸 간 위치를 미리 계산한다.
4. 그 위치가 배열 밖이거나 이미 채워져 있으면 `dir = (dir + 1) % 4`로 방향을 바꾼다.
5. 확정된 방향으로 한 칸 이동하고, `n²`까지 반복한다.

모든 칸을 한 번씩 채우므로 시간복잡도는 O(n²)이다.

## 코드

```js
function solution(n) {
  const answer = Array.from(Array(n), () => new Array(n).fill(0));

  // 오른쪽, 아래쪽, 왼쪽, 위쪽 (x: 행, y: 열)
  const deltaX = [0, 1, 0, -1];
  const deltaY = [1, 0, -1, 0];

  let x = 0;
  let y = 0;
  let dir = 0;

  for (let num = 1; num <= n * n; num++) {
    answer[x][y] = num;

    const nextX = x + deltaX[dir];
    const nextY = y + deltaY[dir];

    // 범위를 벗어나거나 이미 채워진 칸이면 시계방향으로 회전
    if (
      nextX < 0 ||
      nextY < 0 ||
      nextX > n - 1 ||
      nextY > n - 1 ||
      answer[nextX][nextY] !== 0
    ) {
      dir = (dir + 1) % 4;
    }

    x += deltaX[dir];
    y += deltaY[dir];
  }

  return answer;
}
```

> 여기서 `x`는 행, `y`는 열이므로 "오른쪽"은 `deltaY`가 +1이다. 좌표평면의 x/y와 반대라 헷갈리기 쉽다. 방향 배열과 회전 조건은 힌트를 참고해 풀었다.
